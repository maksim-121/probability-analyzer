# Анализатор вероятностей (рабочее название)

Веб-приложение: пользователь описывает случайные факторы и правило, как они складываются в итог,
а приложение методом Монте-Карло считает вероятность события, разброс и главных виновников.

## Откуда движок — из Snow Boom

| Snow Boom (слот)                         | Анализатор                                          |
|------------------------------------------|-----------------------------------------------------|
| Лента барабана: символ + вес             | Фактор с таблицей «значение — вес» (опоздание 0/5/10/20 мин) |
| Генератор с сидом (STRIP_SEED)           | Тот же генератор с сидом: один сид даёт один и тот же ответ |
| Один спин                                | Один прогон сценария («один день»)                 |
| Подсчёт выигрыша по линиям               | Формула итога: старт = max(Иван, Мария, переговорка) |
| RTP = средний выигрыш                    | Средняя задержка                                    |
| Hit rate = доля выигрышных спинов        | P(событие) = доля прогонов, где совещание сорвалось |
| ± погрешность, 1.96·√(p(1−p)/N)          | То же самое для любой вероятности                  |
| Точный расчёт базы + MC бонуса           | Проверка: на простом сценарии MC = точной формуле  |
| Sticky Wild → нужна память → только MC   | Зависимые факторы (дождь → и автобус, и обед) → только MC |
| Сверка Python ↔ JavaScript               | Тот же приём: две реализации считают одно и то же  |

## Пример-прототип (прототип/meeting_mc.py)

Совещание в 14:00, «вовремя» = задержка не больше 5 мин.
- Иван, автобус: 0 / 5 / 10 / 20 мин с весами 50 / 30 / 15 / 5
- Мария, обед до 13:50, затягивается на 0 / 10 / 20 мин (60 / 30 / 10), запас 10 мин
- Переговорка: прошлое совещание затягивается в 25% случаев на 5–15 мин

Результат на 1 000 000 прогонов (сид 20261117):
- P(вовремя): MC 54.09% ± 0.10%, точно 0.80 · 0.90 · 0.75 = 54.00%
- средняя задержка 6.2 мин, медиана 5 мин, P90 = 12.9 мин
- чаще всего срыв из-за переговорки (45%) и Ивана (39%)
